HE30 Hall key mapper

Use the stock driver’s live Hall display to start the stream. This page listens to the HE30’s incoming reports and sends no commands.

  1. In a separate tab, connect to the alternate HE30 driver and turn on its live Hall travel monitor. Leave that tab open.
  2. Choose Listen to HE30. Select a key below, press and release only that physical key, then choose Save key sample. Use the mouse or another keyboard to operate the page.
  3. Download the samples, then stop the monitor in the driver that started it so it can restore its setting.

Slots come from the alternate driver's layout. The capture records Hall report identities so you can check that layout on your unit. Electrical sensor coordinates require separate evidence.
