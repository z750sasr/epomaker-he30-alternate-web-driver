The loop counter measures iterations, not milliseconds or polling rate. Repeated reads should increase it. This page sends only read commands; it does not change settings, enter recovery or flash.

If only HE30 Upgrader appears

The application has not been observed. Save the flasher log and stop repeating the same image. The recorded RAM stage can be inspected later with the probe; USB alone cannot distinguish a loader rejection from a failure before USB starts.
