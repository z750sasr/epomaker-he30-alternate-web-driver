2 · Sensor groups

Confirmed group wiring

Your continuity measurements confirm Group 1 → PB10, Group 2 → PC13 and Group 3 → PC14. The defaults already use these connections. After calibration, check that pressing a physical key changes the matching card below. Alternate group order and settling are advanced options for troubleshooting.

Applying a different group order invalidates calibration. Applying settings releases current inputs and requires the keys to be released before typing resumes. It does not save to flash.

3 · Calibrate

Learn released and fully pressed readings

Apply any group changes first. Release all keys, begin calibration, and wait for the released readings. Then fully press and release keys as prompted below.

4 · Tune keys

Key settings

Click a key card to edit it. Normal bindings and Fn bindings latch when the physical key actuates. Fn is momentary.

Copy tuning changes actuation, hysteresis, Rapid Trigger and dead zones. It preserves each key's normal/Fn bindings and disabled state. Changes stay in the page until Apply.

5 · Lighting

Key LEDs and light bar

PA10 · RGB supply

Pin43 / PA10 reaches the LED supply circuit. Its enable polarity is still unknown. v0.7 starts with PA10 floating and RGB data paused. These buttons use only weak input pull resistors, then release the pin after ten seconds; they never select a strong output.

No power-control status.

During each test, measure PA10 and the first LED V+ relative to verified GND. Record which test raises LED V+. External resistors can overpower a weak pull, so no change does not disprove the wiring. Power tests are never saved. Set a nonzero Solid color before testing; bar lighting remains separately controlled.

v0.8 drives PA10 HIGH to enable the traced Q1/P-channel power circuit. Both LED data lines are held low first, then RGB waits10ms. Supply enable is automatic on boot; these buttons provide a session-only override.

The MCU output is its own I/O voltage, not5V. Confirm LED V+ with your multimeter. If power is enabled but LEDs remain dark, check the supply voltage before changing waveform settings. Turning the supply off pauses RGB until enabled again or rebooted.

PB15 drives the36 key LEDs. PB5 drives the5-LED light bar. Select a physical key card above to edit its color or identify its LED. Per-key colors appear in Per-key mode.

6 · Keep settings

Save or back up a profile

Save writes the custom journal only when requested, including lighting on v0.6. Key profile export includes mappings, tuning and calibration; lighting has its own JSON export above. Import changes a page draft; Apply sends it, then Save makes it persistent. A full firmware reflash clears the journal, so export both profiles first. Reset affects custom RAM settings and does not restore manufacturer firmware.

Raw status and evidence limits
No status read.

Status fields are read in sequential USB chunks and are not an atomic scan-wide snapshot. A running USB application does not by itself validate every physical mapping or calibrated distance.
