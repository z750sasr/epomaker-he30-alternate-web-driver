The three-bank test drives PC13, PC14 and PB10 using the donor's active-low scheme. It does not send typing input or save calibration. If readings do not follow your keys, save the report so we can revise the pin hypothesis.

The guide records a single clear sensor change after a stable press and release, then advances to the next key. The selector and assignment button remain available for manual corrections. Labels are local notes; they do not program keyboard assignments.

3. Test the LED output

Stop sampling before testing RGB. Try a dim color on the first output, then the second. A successful transfer reports that the MCU sent data; it cannot confirm an LED received it.

Brightness is 12/255 per selected color; the firmware caps every component at 16. Both paths use the donor's 0x8/0xE serial waveform. If neither output lights, that does not identify an I²C controller or prove the LEDs are faulty. Send black before leaving the test.
