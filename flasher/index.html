Recovery & firmware

Enter recovery, select a raw firmware image, and follow its update from start to reconnect.

1. Keyboard

Disconnected

Connect the HE30 to get started. Close other keyboard configuration tabs first.

Recovery does not require selecting firmware. If several keyboards are authorized, Connect & enter recovery lets you choose one. Keyboard and media input interfaces are excluded automatically.

Returning to normal keyboard mode

Before an update, unplug the keyboard’s USB for three seconds, then reconnect it. Disconnect probe leads as well if attached. The standalone effect of the OEM finalize command is unverified, so this page uses the tested power-cycle procedure.

3. Update

Select a firmware image and connect the keyboard.

The selected file stays available during the recovery transition. A browser permission prompt may require one additional click. Once erasing begins, keep USB connected.
